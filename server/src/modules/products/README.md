# Lưu ý về sản phẩm trong dự án

## Thông tin sản phẩm

- Tên sản phẩm: Tên sản phẩm phải được viết theo chuẩn ngôn ngữ sử dụng, không biết tắt hay kí tự đặc biệt. Tên sản phẩm chuẩn phải tuân theo quy định sau:

* Loại sản phẩm + Giới tính có thể sử dụng (nếu có) +','+ loại kiểu dáng (nếu có)+ ','+ Chất liệu (Nếu có) +','+ phong cách (nếu có)+','+ phù với với hoạt động nào (nếu có).
  Ví dụ : Áo thun giữ nhiệt nam, form dáng chuẩn , phong cách năng động trẻ trung, phù hợp hoạt động thể thao.
